# 使用 Create React App 入门

该项目由 [Create React App](https://github.com/facebook/create-react-app) 引导创建。

## 可用脚本

在项目目录中，你可以运行：

### `npm start`

以开发模式运行应用。\
在浏览器中打开 [http://localhost:3000](http://localhost:3000) 查看。

当你修改代码时页面会自动重新加载。\
你也可能在控制台看到任何代码检查（lint）的报错信息。

### `npm test`

以交互式监听模式启动测试运行器。\
更多信息见[运行测试](https://facebook.github.io/create-react-app/docs/running-tests)章节。

### `npm run build`

为生产环境构建应用到 `build` 目录。\
它会在生产模式下正确打包 React，并针对最佳性能优化构建。

构建产物已最小化，文件名包含哈希值。\
你的应用已准备好部署！

更多信息见[部署](https://facebook.github.io/create-react-app/docs/deployment)章节。

### `npm run eject`

【注意：这是单向操作。一旦 `eject`，就无法撤回！】

如果你对内置的构建工具和配置不满意，可以随时执行 `eject`。该命令会从你的项目中移除那一个聚合的构建依赖。

相应地，它会把所有配置文件以及相关的传递依赖（如 webpack、Babel、ESLint 等）复制到你的项目中，让你完全掌控它们。除了 `eject` 之外的其他命令仍然可用，但它们会改为指向复制出来的脚本，以便你进行调整。从这一步开始，一切配置维护都需要你自己负责。

你并不需要一定使用 `eject`。默认精心挑选的功能集已经适合小型和中型部署，你不必为了使用而使用它。不过，我们也理解当你准备好进行深度自定义时，没有这个能力会不方便。
